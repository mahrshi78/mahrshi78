# Task - 3: Secure Code Assessment

Assess an application source code for common security weaknesses and coding flaws.

## Task requirements
- Choose an application and examine its source code.
- Use static code analysis tools or perform a manual security review.
- Recommend secure coding practices.
- Prepare a report documenting vulnerabilities and recommended fixes.

## Add to this folder
- Assessment report
- Source code or assessed project reference
- Scan/test evidence
- Remediation documentation
