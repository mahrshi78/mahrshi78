# Task - 5: Secure File Sharing System

Build a secure file-sharing application using Python or Node.js.

## Task requirements
- Allow authenticated users to upload and download files securely.
- Encrypt files before storing them on the server.
- Implement role-based access control.
- Optional: Generate temporary download links with expiration times.

## Add to this folder
- Application source code
- Requirements/dependency files
- Screenshots and test evidence
- Project documentation
