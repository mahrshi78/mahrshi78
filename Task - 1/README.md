# Task - 1: Network Packet Analyzer

Develop a Python application to capture and inspect network packets.

## Task requirements
- Capture packets transmitted over an authorized network.
- Inspect packet and protocol behavior.
- Extract source IP, destination IP, protocol type, and packet data.
- Use Python libraries such as Scapy or Socket.
- Present captured information in a clear format.

## Add to this folder
- Source code
- Requirements/dependency files
- Output screenshots or demo evidence
- Project documentation
