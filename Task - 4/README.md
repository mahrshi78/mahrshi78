# Task - 4: Network Intrusion Detection System

Configure a network intrusion detection solution using tools such as Snort or Suricata.

## Task requirements
- Configure an IDS solution.
- Create and customize rules to identify suspicious or malicious network activity.
- Monitor authorized network traffic.
- Generate alerts and implement basic response actions.
- Optional: Build a dashboard or graphical report.

## Add to this folder
- IDS configuration and rule files
- Dashboard/source code, if developed
- Screenshots and test evidence
- Project documentation
